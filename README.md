# DataLemur SQL Practice

This repository contains my solutions to **DataLemur SQL interview questions** as I practice SQL for **Data Analyst interviews**.

## About

I am using this repository to:

* Strengthen my SQL fundamentals
* Improve problem-solving and query-writing skills
* Practice common SQL interview patterns
* Keep track of my SQL practice

## Topics Covered

* SQL Basics
* Filtering with `WHERE`
* Aggregate Functions
* `GROUP BY` and `ORDER BY`
* `CASE WHEN`
* JOINs
* SELF JOIN
* Date and Time Functions
* Subqueries
* CTEs
* Window Functions

## Tools

* PostgreSQL
* VS Code
* Git & GitHub

## Practice

Each solution includes comments explaining the question and the SQL logic used.
